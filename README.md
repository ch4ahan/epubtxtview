# 책갈피 — 개인용 소설 텍스트 뷰어

내 TXT 소설 컬렉션을 **서재처럼 관리**하고, **페이지 넘김 방식으로 읽고**,
**형광펜과 메모를 달고**, 그 발췌를 **기록 카드 이미지로 추출**하며,
필요하면 **EPUB으로 내보내는** 오프라인 우선 개인 뷰어입니다.

설치 없이 브라우저에서 바로 쓰고, 홈 화면에 추가(PWA)하면 앱처럼 동작합니다.
인터넷 없이 작동하며 서버·계정·동기화가 없습니다. **폰 1대 단독 사용**을 전제로 합니다.

---

## 바로 써보기

이 폴더를 정적 서버로 띄우면 됩니다. (서비스워커/PWA 때문에 `file://` 직접 열기는 일부 기능이 제한됩니다.)

```bash
# 아무 정적 서버나 사용 가능
python3 -m http.server 8080
# 또는
npx serve .
```

브라우저에서 `http://localhost:8080` 접속 → **＋ 책 추가**로 TXT를 불러오세요.
폰에서는 같은 네트워크의 PC 주소로 접속하거나, HTTPS로 배포 후 "홈 화면에 추가"를 누르면 됩니다.

## 주요 기능

| 영역 | 내용 |
|------|------|
| **서재** | TXT 1개 = 책 1권. 표지 지정/자동 텍스트 표지. 목록↔그리드 토글. 정렬(최근/제목/추가순). 완독 뱃지·진행률. 롱프레스 메뉴. |
| **뷰어** | 페이지 넘김(스크롤·애니메이션 없음). 좌표 기반 **자유 터치 영역**(기본 U자, 재배정·크기 조절 가능). 글씨/문단/줄/여백 조절, 다크·세피아·라이트 테마. **실시간 이어보기**(강제 종료에도 복원). 목차 자동 인식. 완독 처리. |
| **형광펜·메모** | 한지색 4색. 각 형광펜에 메모. **문장 기반 위치 저장** → 더 긴 업데이트 파일로 갈아끼워도 자동 재연결. 못 찾으면 **미연결 보관함**에 보존. |
| **북마크** | 읽던 페이지를 북마크. 목차·북마크 모아보기에서 바로 이동. 문장 기반 위치라 업데이트에도 따라감. |
| **기록 카드** | 형광펜/북마크 발췌를 차분한 편집형 **세로 카드 PNG**로 추출. 작품명·날짜 캡션 선택. 개별/전체 모아 추출. |
| **EPUB 내보내기** | TXT → "○○화" 챕터 분리 EPUB. 표지 포함. 의존성 없는 자체 ZIP 조립. |
| **백업** | 형광펜·메모·읽기 기록·책 등록 정보를 **JSON 한 파일**로 내보내기/불러오기. |

## 저장 방식 (중요)

- **본문 TXT는 앱 안(IndexedDB의 `texts` 저장소)에 한 번 보관**합니다. 그래서 앱을 껐다 켜도
  **재연결 없이 바로** 열리고, 원본 파일을 옮기거나 지워도 영향이 없습니다.
  (책 메타와 본문을 분리 저장해, 읽던 위치 저장은 가볍고 빠릅니다.)
- 이 데이터는 **앱 데이터**라 일반적인 "캐시 정리/폰 청소"로는 지워지지 않습니다.
  (앱 데이터 삭제·앱 제거 시에만 사라지므로, 가끔 **JSON 백업**을 받아두면 안전합니다.)
- **형광펜·메모, 읽기 기록, 책 등록 정보, 설정**도 모두 IndexedDB에 저장됩니다.
- 백업에는 본문이 포함되지 않습니다(용량 절약). 새 기기에서 복원하면 책은 **"본문 재연결 필요"**
  로 표시되고, TXT를 한 번 골라주면 형광펜·메모가 문장 기반으로 제자리를 다시 찾습니다.

## 폰 바꿀 때

1. 새 폰에 앱(PWA) 설치
2. **JSON 백업 불러오기** → 서재 목록·형광펜·메모·읽기 기록 복원
3. 소설 TXT 파일들을 새 폰으로 복사
4. 서재에서 **"재연결 필요"** 표시된 책을 열고 **본문 파일 다시 연결** → 형광펜·메모 자동 재배치

## APK 만들기 (GitHub Actions — PC 설정 불필요)

이 저장소에는 **GitHub에서 APK를 자동으로 빌드하는 워크플로**가 들어 있습니다
(`.github/workflows/android.yml`). 안드로이드 스튜디오나 PC 설정 없이 GitHub에서 바로 받습니다.

1. GitHub 저장소 → **Actions** 탭 → **Build Android APK** 선택
2. 이 브랜치로 푸시하면 자동 실행되며, **Run workflow** 버튼으로 수동 실행도 가능
3. 빌드가 끝나면(초록 체크) 실행 페이지 하단 **Artifacts → `chaekgalpi-debug-apk`** 를 내려받기
4. 압축을 풀면 `app-debug.apk` → 폰으로 옮겨 설치
   - 설치 시 안드로이드의 **"출처를 알 수 없는 앱 설치 허용"** 을 켜야 합니다(디버그 서명 APK).

> 동작 원리: 워크플로가 웹 자산을 `www/`로 모으고 → [Capacitor](https://capacitorjs.com/)로
> 안드로이드 프로젝트를 생성한 뒤 → Gradle로 디버그 APK를 빌드합니다.
> 안드로이드 WebView에는 File System Access API가 없어, 본문 TXT는 "폴백 저장" 경로로 동작합니다.

### 로컬에서 직접 빌드하려면

```bash
npm install
npm run build:www
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug   # → app/build/outputs/apk/debug/app-debug.apk
```

## 파일 구조

```
index.html          앱 셸 (3개 화면)
manifest.json       PWA 매니페스트
sw.js               오프라인 서비스워커
icon.svg            앱 아이콘
css/styles.css      테마/레이아웃 (라이트·세피아·다크)
js/
  zip.js            의존성 없는 ZIP 작성기 (EPUB용)
  db.js             IndexedDB 래퍼
  encoding.js       UTF-8 / EUC-KR 자동 디코딩
  chapters.js       "○○화" 목차 자동 인식
  highlights.js     문장 기반 형광펜 앵커 & 재연결
  viewer.js         페이지 넘김 뷰어 + 터치 영역 + 형광펜
  cards.js          기록 카드 PNG 렌더
  epub.js           TXT → EPUB
  backup.js         JSON 백업
  excerpts.js       형광펜 모아보기 / 카드 추출
  library.js        서재
  app.js            라우터·모달·파일 처리·초기화
```
